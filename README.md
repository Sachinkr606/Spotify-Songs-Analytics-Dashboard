
# 🎵 Spotify Songs Analytics Dashboard

## 📊 Project Overview

This project is a complete **Data Analytics and Visualization project** based on Spotify songs.

The goal of this project is to analyze songs released between **2000 and 2023** across multiple Indian languages and identify patterns related to:

- 🎵 Songs
- 🎤 Artists
- 🌍 Languages
- ⭐ Popularity
- ▶️ Streams
- 💃 Danceability
- ⚡ Energy
- ❤️ Valence
- 🎧 Acousticness
- 🔊 Loudness
- ⏱️ Tempo

The final result is an interactive **Power BI dashboard** that provides insights into more than **35K songs** across **16 languages**.
